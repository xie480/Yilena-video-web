# 仿 B 站项目 v1.0

一个基于 **Spring Boot + Vue 3** 的原创练手项目，目标是实现一个1:1还原哔哩哔哩使用体验的视频社区系统，包含 **用户端** 与 **管理端** 两套界面，以及搜索、弹幕、评论、私信、动态、审核、统计分析等功能。

> 本项目为阶段性总结型练手项目，完整源码、接口文档与 SQL 脚本可在对应仓库中查看。

* * *

## 项目简介

该项目围绕“视频内容社区”的核心流程展开，覆盖：

* 用户注册、登录与资料管理
* 视频浏览、播放、互动与推荐展示
* 搜索、历史记录、收藏、投稿、动态、私信等社区功能
* 管理员审核、用户管理、动态管理、日志管理与趋势分析
* 定时清理过旧数据，保持系统运行整洁

## 功能概览

### 用户端

#### 1. 注册 / 登录

* 实时表单校验
* 用户密码加密处理
* 后续可扩展邮箱验证

#### 2. 首页

* 推荐视频展示
* 实时热搜 Top10
* 搜索历史记录展示与清理

#### 3. 视频播放页

* 展示标题、作者、简介、标签、日期等信息
* 实时弹幕发送与接收
* 关注 / 取消关注 / 特别关注
* 多级评论、@、图片评论、分页加载
* 点赞、投币、收藏、分享
* 自动连播下一条推荐视频

#### 4. 搜索页

* 搜索词加密传输与存储
* 关键词高亮
* 视频多条件筛选
* 用户搜索与粉丝量筛选
* 搜索结果分页

#### 5. 个人主页

* 修改头像、昵称、简介
* 修改密码
* 展示投稿、收藏、投币视频
* 投稿合集管理
* 收藏夹管理
* 动态管理

#### 6. 动态页

* 发布文字、图片、多图、视频、标签动态
* 关注流动态列表
* 单用户动态聚合
* 敏感词过滤
* 视频转发到动态
* 动态点赞与评论

#### 7. 私信页

* 互关用户实时聊天
* 新视频发布通知
* 消息已读 / 未读
* 消息删除与撤回
* 多媒体消息支持
* 互动通知与系统通知
* 订阅通知

#### 8. 历史页

* 按日期记录每日浏览视频
* 支持开启 / 关闭历史记录
* 一键清空历史

#### 9. 投稿页

* 视频上传与投稿
* 标题、简介、标签编辑
* 敏感词过滤
* 投稿状态管理
* 数据总览
* 粉丝、点赞、收藏趋势分析
* 评论管理与搜索

* * *

### 管理端

#### 1. 登录页

* 表单校验

#### 2. 首页

## 自动清理过旧数据

项目使用 Spring Task 每天凌晨 2 点自动清理以下数据：

* 半年前的聊天记录
* 每个用户十五天前的历史记录
* 单日搜索量小于 100 的搜索数据
* 半年前的日志数据
